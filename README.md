# String Operations

## Overview

This project contains Java programs for basic string operations.

The programs can:

* Check whether a string is a palindrome.
* Count the number of vowels in a string.

## Programs

1. PalindromeChecker.java
2. VowelCounter.java

## Technologies Used

* Java
* Scanner
* String methods
* Loops
* Conditional statements

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure JDK 21 or above is installed.
3. Run `PalindromeChecker.java` to check a palindrome.
4. Run `VowelCounter.java` to count vowels.
5. Enter a string when asked.

## Example

Input:
madam

Output:
The string is a palindrome.

Input:
hello

Output:
Number of vowels: 2
